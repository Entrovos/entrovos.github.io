Peaks

*Visit the 'Peaks' repository.*

The Premise

Peaks a simple console game written entirely in C#. It plays as a simple shoot-em-up, space combat game where you select a difficulty ranked on a set number of alien enemies you must shoot and defeat. Once the targeted number is reached, you win the game. You are given three lives, in which losing all of them means you lose.

The Purpose

This game was done for the final project of my Programming 1 class in first college semester of 2023, where we had to make a game in Visual Studio in C# that ran using the console. I had total freedom in what I'd choose to make, and classic space shooters such as Galaga or Space Invaders have always been some of my favorite past-times.
